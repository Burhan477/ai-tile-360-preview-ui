# Surface masks

Masks tell the 360° viewer where a surface (floor or wall) is in a
panorama. The uploaded tile is drawn only where the mask is white; everything
else in the photo (walls, furniture, windows, doors) stays untouched.

## Format

- **Naming:** `<panorama-name>-floor.png` / `<panorama-name>-wall.png` (e.g.
  `living-room-floor.png` for `living-room.jpg`).
- **Projection:** equirectangular, **same framing and 2:1 aspect** as its panorama,
  so pixel (x, y) in the mask describes pixel (x, y) in the panorama.
- **Resolution:** may be lower than the panorama (2048 × 1024 is plenty); it is
  stretched over the same sphere.
- **Values:** 8-bit grayscale PNG. Only the red channel is read, so RGB works too.
  - `255` (white) — floor: tile fully visible
  - `0` (black) — not floor: panorama unchanged
  - in between — partial blend; use 1–3 px of soft edge along skirting boards
    and furniture to avoid jagged lines
- Paint **visible floor only**: leave rugs, furniture legs and anything standing
  on the floor black if they should stay in front of the tile.

## Creating a mask for a real photo

1. Open the panorama in an image editor and add a new layer.
2. Fill the visible floor white and everything else black (a feathered
   selection of 1–2 px gives smooth edges).
3. Export only the mask layer as grayscale PNG with the same aspect ratio.
4. Register it in `src/constants/panoramas.ts` under `floor`:
   - `mask` — path to the PNG
   - `cameraHeight` — camera height above the floor in metres (≈ 1.6 for a
     handheld eye-level capture); controls how large the tiles appear
   - `gridOffset` — shifts where tile joints start on the floor, in metres
   - `gridRotation` — radians; turn the grid until joints run parallel to the walls

## Wall masks

Same format; paint the **tileable wall** white and leave windows, doors, their
frames, skirting, furniture, floor and ceiling black. Register it under `wall`:

- `room` — distances in metres from the camera to the left/right (`minX`/`maxX`)
  and front/back (`minZ`/`maxZ`) walls. The view at the image centre looks
  down −Z, and +X is to the right. The walls are modelled as a box, so the
  tile follows each wall's perspective.
- `cameraHeight`, `wallHeight` — camera and ceiling height above the floor;
  tile rows start at the floor line
- `yaw` — radians; turn the box until tile joints follow the wall corners
- `gridOffset` — `[along, up]` shift of the tile grid in metres. The grid runs
  continuously around the room (front → right → back → left), starting in the
  front-left corner.
